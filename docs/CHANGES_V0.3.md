# Idle Cash & Cartel — lista modificari V0.3 (2 nov 2026)
Versiuni salvate: v0.1 initial (zip), v0.2 camera+side view (git cc5a14f, GitHub cyuralexandru-design/idle-cash-cartel), arta bruta (assets/raw).

## A. Arena / raid
1. Personaje: re-facut rig. Vedere 3/4 (~30 grade stanga/dreapta dupa miscare), picioare independente, brate la fel. Hero+enemies = prompturi noi pentru parti (walk-ready). [cere prompt]
2. Peisaj: de-construit in module de strada (asfalt, trotuar, bordura, marcaje, fatade/ziduri, gard, canal, felinare) asamblate procedural. [cere parti separate]
3. Shop raid: iconite lipsa la iteme -> folosesc iconitele existente (130 icons) sau cer prompt.
4. Arme: NU 6 odata. Un singur set de arma, upgrade treptat pe waves (tier-uri), fara merge/6 sloturi.
5. Gloante: sprite real + animatie (tracer, casing, muzzle flash), nu bile colorate. Plasma/laser proprii.
6. Bani pe jos: bancnote (mai mari = valoare mai mare), lingou aur pentru gold. Din icons/fx existente.
7. Joystick: dreapta, apare doar la atingere (floating).
## B. Meta / meniu
8. Meniu jos: iconite pe taburi (lipsesc acum).
9. Raid = ecran principal dupa loading. Buton RAID jos-mijloc langa celelalte taburi. Centru: Chapters in scroll orizontal (ca Survivor.io): deblocate color, blocate alb-negru + lacat. V1: 3 capitole x 15 waves; elite la 5, super elite la 10, boss la 15.
10. Workshop -> pastreaza numele, devine INVENTORY ca la Survivor.io: erou sus; stanga sus->jos: arma, lant (chain), manusi; dreapta sus->jos: sacou, pantaloni, pantofi. Raritati: common, uncommon, rare, epic, legendary, ultra. Iteme cu atack/defence/bonusuri, merge/upgrade.
11. Crew: fiecare membru da bonus permanent (attack, defence, gold, cash, xp...), % creste cu nivelul.
12. Story: conversatii erou <-> crew (dialog cu portrete).
13. Mapa cladirilor (nu lista): harta data de user. Cladire blocata = alb-negru + lacat; deblocata = color cu culoarea nivelului (raritati). Tap -> +5% scale, buton verde 'Manage' dedesubt. Manage -> interior cladire cu obiecte upgradabile (se schimba vizual luxul), managerul din crew apare in scena. Prima intrare = tutorial: managerul vorbeste cu eroul (imagine de prezentare/conversatie per manager). [cere prompturi cu imagine per cladire: stare blocata/deblocata/niveluri + interior + scena dialog]
